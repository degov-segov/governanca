# Cockpit de Governança — SEGOV / TJCE

Site estático pronto para GitHub Pages.

## Publicação
Envie todos os arquivos deste pacote para a raiz do repositório e, no GitHub:
**Settings → Pages → Deploy from a branch → main → /(root) → Save**.

A página inicial é `index.html`.

## Arquivos
- `index.html`: página principal
- `projetos.html`: 21 projetos estratégicos
- `rede.html`, `processos.html`, `orcamento.html`, `pac.html`, `contratos.html`, `riscos.html`, `indicadores.html`, `gam.html`: páginas internas
- `estilo.css`: identidade visual compartilhada
- `app.js`: navegação e botão automático de retorno
- `404.html`: página de erro

O PAC está, por enquanto, apontando para o dashboard já publicado no endereço anterior.
